# 健康日汇总 JSON（v1）

适用版本：网页 v2026-10-07.6。导入入口：健康 → 导入健康 JSON。文件只在当前设备解析，不上传。

这是本应用约定的精简日汇总格式，**不是苹果健康原生导出格式，也不直接兼容任意第三方 JSON**。苹果健康的“导出所有健康数据”提供 XML，见 [苹果官方说明](https://support.apple.com/en-ca/guide/iphone/iph5ede58c3d/ios)。快捷指令可查询健康样本，苹果确认睡眠分期查询能力，见 [快捷指令更新说明](https://support.apple.com/en-hk/101583)。本版完成网页接收端，尚未提供经过 iPhone 实测的导出快捷指令，尤其训练会话读取需要单独验证。

## 文件内容

[health-import-example.json](health-import-example.json) 是**虚构测试样例**，不是实际健康记录；不要导入到个人记录中。它用于导出工具和本地测试对接。

顶层字段：`app: "kcal-health"`、`version: 1`、带时区的 `exportedAt`、`days` 数组。每个日期最多一条，只能是有效的今天或历史日期。

每个日对象包含 `date` 和至少一个类别；不包含的类别保留现有数据：

| 类别 | 字段及单位 | 口径 |
| --- | --- | --- |
| `energy` | `active`、`basal`，数值型 kcal，两项都必须存在 | 当日去重后的活动/静息日汇总；训练热量不再次相加 |
| `training` | 会话数组，每项 `id`、`type`、`durationMinutes`（分钟）；可选 `startAt`、`distanceKm`（km）、`energyKcal`（kcal） | 同一天的完整列表；ID 必须稳定且当天不重复；开始时间对应 date；空数组明确表示该日无训练 |
| `sleep` | `asleepMinutes`（实际睡着分钟）；可选同时提供 `startAt` 和 `endAt`，可选 `stages` | 夜间睡眠归醒来日期。阶段只支持 `core`、`deep`、`rem`，单位分钟；总和不能超过实际睡眠。仅在床及清醒时长不相加 |

数值不能用字符串，也不能省略单位字段名。`0` 与没有类别不同：0 睡眠或0能量是已记录的数值，缺失表示无记录。训练时长必须大于0。起止时间和 exportedAt 必须带 `Z` 或 `+08:00` 等时区。睡眠 endAt 的日期部分应等于 date，代表导出时区中的醒来日期；网页按设备时区显示时间，旅行跨时区时请核对归档日期。

睡眠起止范围不能短于实际睡眠；起止时间可省略，只导入实际睡着时长。**网页接收已汇总分钟数，不接收原始健康样本**，不会自行证明汇总是否去重正确。导出端要处理多设备、重复和重叠时间段，同一时段只统计一次；在床、未细分睡着和分期样本不得简单相加。阶段信息缺失时不猜测。依据 [HealthKit 睡眠类型与重叠样本说明](https://developer.apple.com/documentation/healthkit/hkcategoryvaluesleepanalysis)。

本版睡眠是每日一份汇总，尚不区分多段睡眠、午睡会话，也未加入睡眠评分；训练是会话概况，尚不记录力量训练每组动作。

## 导入与迟到数据

1. 建议次日早晨导出最近7天与今天；同一文件可包含昨日能量、今日醒来的睡眠及历史训练。缺失数据不要填0，也不要输出空训练列表来冒充未同步。
2. 先检查每项日期、合计和来源，与健康 App 对照；点击确认后再次显示将更新的记录。
3. 同时间或更旧的导出跳过，较新的日汇总替换该类别，不累加。导出工具重跑时应保持会话 ID 和实际导出时间正确。
4. 手动记录更新晚于 exportedAt 时保留手动记录；新文件将覆盖较早手动记录时，确认提示会明确说明。未列出的日期和类别始终保留。
5. 全部类别一次写入快照，取消、验证失败、存储失败或其他窗口已更新时不部分导入。文件限制5 MB，使用精简日汇总，最多3660个日期。

## 完整备份

设置中的完整备份升级为 **v6**，包含训练与睡眠。存储继续使用原来的 `kcal.data.v5` 键，以保留现有快照比较与并发保护；这是键名，快照内 version 为6。打开旧v5快照无需写入，首次成功保存原子升级，不删除旧独立存储键。旧代码遇到version6会停止写入，防止忽略新类别后覆盖。

恢复旧v1–v5备份时，不存在的训练/睡眠类别保留；v6完整备份明确包含两类，即使为空。完整备份与健康导入是不同入口：完整备份可合并或覆盖整类数据；健康JSON仅更新文件列出的日汇总。版本回退前先保存v6完整备份，旧版本不能读取v6后续记录。
