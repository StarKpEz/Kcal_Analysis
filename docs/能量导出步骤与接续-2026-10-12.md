## 9. 包装JSON并保存

1. 添加“文本”，复制下面模板。
2. 将四处【变量】替换成真正的变量标签。导出时间外面的引号保留；两个日JSON和午夜JSON外面都不加引号。

```json
{
  "app": "kcal-health-energy",
  "version": 1,
  "exportedAt": "【导出时间】",
  "from": "2026-10-01",
  "through": "2026-10-11",
  "dailyTotals": [
    【活动日JSON】,
    【静息日JSON】
  ],
  "boundarySamples": [
    【午夜JSON】
  ]
}
```

3. 添加“获取字典”，输入明确选择完整模板的文本。用于检查完整JSON能否解析。
4. 添加“获取文本”，输入选择这一步解析出来的完整字典。
5. 添加“设定名称”，输入为完整字典转换后的文本，名称填写 `kcal-energy-2026-10-01-11.json`。
6. 添加“存储文件”，输入选择重新命名的项目，开启询问存储位置。
7. 运行并查看五个数量；点击“好”继续，选择文件保存位置。
8. 如果报错，记录停在哪个动作。不要转回全天原始样本循环。

分隔符只分两种：日数值/日日期/字典separator使用竖线；午夜字典片段之间使用英文逗号。没有反引号，也没有单引号。
